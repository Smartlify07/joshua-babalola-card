The Three Core Technologies of Web Development

scribed · 22 oct 2026 · — words

sometimes the internet feels like magic, but every page you have ever opened runs on three plain, wonderful ideas. writing this down so it sticks: the skeleton, the wardrobe, and the muscle that quietly throws the whole thing together before anyone even looks.

1. HTML — the skeleton

← bones!

HTML is what the page is — pure structure. Angle brackets are honest little tags: heading, paragraph, list, image, form, link. No styling, no drama, no lies. The real craft is semantics: use <header>, <nav> and <article> where they belong and browsers, search engines and screen readers all read your document as a document. HTML carries meaning, not looks.

2. CSS — the wardrobe

← outfit

Cascading Style Sheets decides what everything looks like. HTML says what a thing is; CSS says how it's dressed — colour, spacing, fonts, layout (flex and grid instead of ancient table hacks), animation, and how it reflows on every screen size. The cascade is why it's clever: rules pour down from broad to specific, so one stylesheet can restyle a thousand pages in a single edit.

3. PHP — the muscle

← server-side!

PHP works before the browser sees anything. It runs on the web server, assembles the HTML on the way out, reads databases, handles forms, logs people in and personalises pages. Whenever two visitors get different results from the same phone call, PHP is quietly flexing.

<?php echo "Hello, " . htmlspecialchars($name); ?>

✦ the handshake

picture a visit to any site: the browser asks for a page → the server runs the PHP → PHP prints HTML (pointing at a CSS file) → the browser draws the structure → smooths on the wardrobe. structure first, style second, brain behind the scenes. three plain files, one very organised conversation.

PS: JavaScript earned its own notebook — that page is still being written. stay curious.
